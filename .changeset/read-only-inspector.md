Add a native in-app inspector dock for watch-mode embedded apps. Right-click
Inspect element, browse a virtualized host tree, inspect props and painted
geometry, or pick an element without activating it. Inspector state is local to
each window and does not remount the application. Retain an optional external
browser companion and automation geometry/picking/highlight commands.
Handle split HTTP request packets reliably with timed blocking reads on accepted
connections.
