'@gpuix/native': minor
---

Add `solid.create_selector(source)` to the Lua runtime. `is_selected(key)` re-runs only the readers of the old and the new key when the selection changes, instead of every row. Solid text, style and prop bindings now skip the host call when their value hasn't changed. Bindings compare with `==`, so a style table changed in place isn't noticed: return a new table instead. Showing, hiding and reordering `solid.Show`, `solid.For` and `solid.Index` slots no longer walks the whole window tree, and reordering a long list no longer takes time proportional to the square of its length. A slot whose new child fails to mount is left unchanged, and the updates queued after it still apply; before, they were dropped. A slot update no longer fails, or mounts the wrong node, when another window renders first, and updates for nodes that are never mounted are dropped at the next event instead of piling up. Updates queued outside an event, such as from a mount effect or a store dispatch, now mark their window for rendering. `set_children` rejects a node from an earlier render when it is called, as `set_child` does, instead of when the batch is applied.
